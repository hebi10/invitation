## 제작 범위
- **총 12종 정지 이미지**, 01~03 심플 / 04~06 감성 / 07~09 화려 / 10~12 커플 캐릭터. 각 시안 480×600px의 PNG 및 WebP 내보내기. 총 24개 개별 파일.
- 4개 그룹 비교 PNG + 12종 전체 비교 PNG + SHA-256 manifest + ZIP. Google Drive 폴더에서 31개 항목 업로드 및 12개 PNG·WebP 파일 존재 확인.
- GIF 파일 신규 생성·반복 정책 설정·공개 하객 페이지 배포·기존 고객 데이터 수정 **없음**. 이 단계는 시안 제작·검토만 수행.
- 01 시안은 **기존 intro-01 파일의 조판을 재현한 검토용 참고 이미지**입니다. PR #100의 원본 GIF/WebP 파일과 SHA를 변경하거나 덮어쓰지 않습니다. 검토용 01 이미지가 원본과 바이트 단위로 동일하다는 뜻은 아닙니다.
- 비교판에서 생성된 일부 아이디어를 480×600으로 리샘플링했으므로 크기 규격은 충족하지만, **원생성 해상도·문자/선명도는 제작 승인 수준으로 검증되지 않았습니다**. 실 GIF의 포스터로 바로 쓰지 말고 03-C에서 최종 프레임 고해상도 재제작이 필요합니다.
