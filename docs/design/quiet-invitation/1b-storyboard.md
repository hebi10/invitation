## A. Light — Quiet Typography

금빛 조명과 큰 화면 와이프를 모두 제거합니다. 아이보리 종이색과 명조 이름만으로 집중도를 만듭니다.

| 프레임 | 설계 시점 | 화면·움직임 |
| --- | ---: | --- |
| A1 Start | 0ms | 종이색, 40px 구분선과 소중한 분께 문구. 이름은 낮은 투명도로 준비. |
| A2 Read | 580ms | 이서준 · 김하은 명조 26~32px, 초대 문구 15px, 날짜 13px. opacity와 최대 12px translate로 1회 등장. |
| A3 Handoff | 1,400ms | 인트로가 사라지고 하객용 본문 표지가 나타남. 별도 광선, 슬라이드, 텍스트 퇴장 동작 없음. |

레이아웃: Paper #FAF9F6 / Ink #282725, 텍스트 최대 328px, 360px 이상 모바일 가로 여백 24px.

## B. Cinema — Editorial Photo

고객의 대표 사진이 주인공입니다. 원래의 검정 셔터 개방과 화면 좌표를 긴 거리 이동하는 전환을 사용하지 않습니다. PC의 바깥쪽은 어두운 빈 띠 대신 인쇄물 느낌의 Soft Paper(#F3EEE5) 캔버스로 연결해 480px 대표 사진이 편집 화보처럼 읽히게 합니다.

| 프레임 | 설계 시점 | 화면·움직임 |
| --- | ---: | --- |
| B1 Start | 0ms | 대표 사진 전체 노출, 약한 단색 어두운 스크림, 건너뛰기. |
| B2 Read | 650ms | WEDDING DAY, 커플 이름, 날짜가 하단에서 한 번 나타남. |
| B3 Handoff | 1,600ms | 현재 하객용 표지로 연결. 이미지를 비행시키지 않고 단일 페이드. |

사진 위 텍스트는 실제 사진별로 수동 대비 검증. 사진이 없거나 로딩이 실패하면 배경 #1D1F1D + 명조 이름 + 날짜로 대체하는 것을 2-A에서 구현합니다.

## C. Envelope — Flat Letter

봉인, 3D 덮개 회전, 삼각형 편지함, 카드 사진 비행을 모두 제거합니다.

| 프레임 | 설계 시점 | 화면·움직임 |
| --- | ---: | --- |
| C1 Start | 클릭 전 | Soft Paper #F3EEE5, 흰 종이 카드 #FFFDF8, 완전한 1px 테두리, 이름과 날짜, 초대장 열기 버튼. |
| C2 Open | 클릭 후 580ms | 카드가 12px 올라간 상태, 버튼은 약하게 표시. 다른 물체 이동 없음. |
| C3 Handoff | 클릭 후 1,100ms | 카드 페이드 후 본문 표지 등장. |

열기 전 자동진행 없음. 건너뛰기는 언제든 선택 가능, 48px 이상 조작 영역을 유지합니다.

## 4. 공통 모션 및 기술 계약

- 기본 easing cubic-bezier(0.22, 1, 0.36, 1), 진입 580ms, 퇴장 420ms, 최대 12px 이동.
- 시작과 본문 읽기 사이 중복 움직임 없음. 종료 시 잔여 오버레이·스크롤 잠금·이미지 숨김 없음.
- 사전 설정값, 해시 진입 및 세션 최초 노출 정책 유지.
- prefers-reduced-motion: reduce에서는 모션 0ms. 사진 누락, GSAP 불러오기 실패, 느린 네트워크 및 resize 시 본문에 안전하게 접근.
- 반응형 점검 320·360·390·430·600·840·1280·1440 CSS px. 600/840은 물리 기기와 다름.
- 1-B 시안 마지막 프레임의 표지는 연결 목표를 보여주는 **샘플 표지**로, 공개 5개 테마의 실제 이미지와 크롭에 대한 검증은 3-A에서 수행.
- 현 단계는 HTML/CSS/JS 독립 프로토타입과 실브라우저 캡처로 한정하며, 앱과 Firebase에는 미적용.
