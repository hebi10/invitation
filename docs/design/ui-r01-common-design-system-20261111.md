# UI-R01 — 청첩장 5종 공통 디자인 시스템 1차 구현

## 기준 및 범위
- 선행 기준: UI-R00 PR #83 (head `8399754`), 현재 5종 public wedding theme에만 적용
- 대상: `src/app/_components/public-invitations/wedding/WeddingBase.module.css`
- 기존 테마 키: `simple`, `classic-r`, `romantic`, `gyeol`, `emotional`
- `vow` 및 제작·관리·결제 UI는 범위에서 제외

## 반영
1. 5종에 한정해 반응형 여백·읽기 폭·터치 크기 관련 공통 토큰을 추가함
2. 초대 글·교통 설명·안내 요약의 작은 화면 장문 줄바꿈 방어
3. 연락처·계좌·방명록 아코디언 요약의 48px 최소 높이
4. 전화/문자·복사·새로고침·페이지 이동·갤러리 컨트롤의 최소 44px 터치 영역
5. 키보드 포커스 시 테마별 `--focus` 색으로 명확한 윤곽선 제공
6. 320px 폭에서 빠른 이동 링크의 줄바꿈 및 가로 넘침 완화

## 보존
- 기존 색상 팔레트, 테마 고유 간격, 웨딩 사진·본문·고객 데이터·기존 링크·조건부 섹션 유지
- React / Firestore / Firebase / Play / 결제 / 계좌 / 방명록 동작 미변경
- 새로운 그림자·그라데이션·애니메이션을 넣지 않음

## 남은 검증
- CSS Modules 및 Next.js 프로덕션 빌드
- 5종 x 320/390/430/768/1440px 시각 캡처, 200% 글자 확대
- 연락처/계좌/방명록 펼침, 갤러리 모달, 달력·지도, 키보드 포커스 회귀
- UI-R00 최신 캡처/manifest QA 통과 후 동일 기준으로 전후 이미지 비교
- 이상 없을 때 PR 순차 병합. 운영 Firebase 및 Google Play 배포는 별도

이 문서는 코드 적용 내역과 확인해야 할 작업을 구분하며, 실기기 또는 CI 성공을 주장하지 않습니다.
