# UI-R02 — 기본형(simple) 모바일 청첩장 리뉴얼

기준: 2026-11-11, UI-R00 PR #83 및 UI-R01 PR #84 기반 스택 작업.

## 실제 코드 변경

- `WeddingBase.tsx`: 기본형 바로가기 3종의 기존 WeddingActionIcon 노출. 갤러리가 없는 경우 사진 보기 링크는 계속 조건부로 제외.
- `WeddingBase.module.css`: `data-design='simple'` 범위의 3열 바로가기, 표지 이후 초대 글 간격, 가족 연락처 펼침, 날짜·시간·장소 정보 행 및 예식 안내 패널, 하단 링크 정리.
- `WeddingCover.module.css`: `.basic` 범위의 이름·날짜·시간·장소 정보 계층, 모바일 줄바꿈 및 320px 안전 여백.
- 기존 결제, 고객 정보, Firestore, 공개 URL, 사진 초점 `focusX/focusY`, 표지 텍스트 위치 `textPosition`, 캘린더 다운로드, 지도, 계좌, 방명록 동작은 수정하지 않음.
- 시안의 임의 인명·일정·주소·계좌·댓글은 적용하지 않음. 모바일 장치 프레임·상태바, 3D, 장식용 그림자/그라데이션/애니메이션은 추가하지 않음.
