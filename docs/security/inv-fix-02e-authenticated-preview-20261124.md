# INV-FIX-02-E — 인증 미리보기 파일럿
- #141의 테스트 slug 전용 공개 projection을 기반으로 소유자 웹 및 모바일 미리보기 API가 기존 Storage URL을 인증 이미지 경로로 변환한다. 비파일럿 경로는 그대로 유지한다.
- 모바일 사진 GET은 서명된 미리보기 토큰과 유효한 세션, 현재 소유권 및 동일 이벤트 ID, 보기 scope, 저장된 이미지 참조를 확인하고 바이트를 읽은 뒤 세션을 재검증한다. 삭제 진행 상태에서는 이미지 응답을 차단한다.
- 브라우저는 정확한 동일 출처의 인증 이미지 경로에만 bearer 헤더를 붙이며, 임시 blob URL로 표시한다. 중복 다운로드 제거, 파일/총량 상한, 취소 및 화면/계정 변경 시 폐기, 실패 시 부분 결과 폐기를 적용한다.
- 기존 저장 데이터, Firebase rules, 운영 설정, 토큰 폐기, 배포는 변경하지 않는다. 파일럿에서는 owner/event에 묶이지 않은 구형 모바일 세션을 새 이미지 권한으로 확장하지 않는다.
- 후속: 실제 테스트 초대장 및 Android/PC 검증, 직접 Firestore 읽기/관리자 저장 편집기/추억 페이지·구형 앱 호환성 및 토큰 폐기 전환 검증. 해당 검증과 운영 승인이 끝나기 전에는 기존 토큰을 폐기하지 않는다. 이미 브라우저나 외부 서비스가 받은 이미지 복사본을 회수할 수는 없다.
