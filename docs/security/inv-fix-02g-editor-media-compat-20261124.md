# INV-FIX-02-G — 웹 편집기 안정 이미지 참조 호환성

공개 게이트웨이 안정 주소를 저장한 초대장이 웹 관리자·고객 편집기에서 표시될 수 있도록 읽기 전용 인증 렌더링을 연결한다. canonical 동일 slug 경로만 인증 GET으로 전환한다. 대표/공유/갤러리/테마별 사진의 화면 및 iframe 미리보기에는 blob URL을 사용하며, 선택·삭제·순서·저장에 사용하는 원래 formState 값은 유지한다. 이미지 주소 집합 변경 시에만 다시 읽고 계정/화면 변경 시 해제한다. 기존 토큰 URL, 정적 이미지, 일반 URL은 유지한다.

범위: 이미 안정 주소를 가진 파일럿의 웹 편집 화면 호환성. 이 PR은 운영 저장 주소 변환, 업로드 계약 전환, Firebase SDK 직접 목록/다운로드 제거, Android 네이티브 이미지 표시·기존 앱 호환, 운영 토큰 폐기를 완료하지 않는다. 브라우저 및 실제 기기 검증 이후 별도 전환 승인 필요. 기존 고객 데이터나 배포는 변경하지 않는다.
