# INV-FIX-02-I — Android 안정 이미지 편집 및 업로드 호환
- 현재 소유자·이벤트·서버 편집 세션·보기/편집 scope로 보호된 모바일 이미지 GET을 추가한다. 읽기 전후 동일 세션 및 소유권을 검증한다. 공개 참조만 허용하는 preview-owner와 아직 저장하지 않은 사진까지 편집하는 editor-owner의 권한을 분리한다.
- Android 편집 이미지와 현재 관리 중인 대표 사진은 정확한 API origin/slug/파일 경로에서만 인증 헤더와 기기 식별자를 전달한다. Expo fetch의 redirect 차단, 크기/형식/길이 검사, 임시 data URI 및 디스크 캐시 금지, 세션 변경·취소 시 결과 무효화. 로컬 개발 허용은 제한된 로컬 호스트에 한정한다.
- 새 앱은 stable-v1 계약을 요청한다. 서버는 지정된 파일럿 slug와 별도 기능 플래그, 소유자 결합 편집 세션을 확인한 경우에만 안정 주소를 반환한다. 원래 저장 path와 API 응답 필드를 유지한다. 이전 앱 또는 플래그 미활성 시 기존 응답 그대로이다.
- 실제 업로드 파일과 기존 다운로드 토큰은 이 PR에서 제거하지 않는다. 기존 서버는 신규 요청의 query를 무시할 수 있으므로 새 앱도 기존 응답을 계속 처리한다.
- 실제 Android 기기에서 비공개/공개/저장 전후, 공유 및 갤러리 용량 검증, 관리자 목록/SDK 의존 제거, 추억 페이지·구버전 호환성 확인이 남아 있다. 운영 플래그 활성화·데이터/토큰 변경·Play/Firebase 배포 없음.
