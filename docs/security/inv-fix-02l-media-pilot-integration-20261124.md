# INV-FIX-02-L — Firebase 파일럿 이미지 이관 통합 검증

- 독립적인 이벤트 관리 버전과 콘텐츠 버전을 분리한다. 읽기 전용 사전검사는 저장소 조회 전후 이벤트·콘텐츠·추억 데이터가 달라지면 성공을 보고하지 않는다.
- 기존 Firebase 에뮬레이터 테스트 묶음에 UUID 기반 가상 청첩장 통합 테스트를 추가한다. 프로젝트 ID와 Firestore/Storage의 로컬 호스트를 먼저 검증하므로 운영 환경에서 실행하지 않는다.
- 실제 서버 업로드(원본·본문·썸네일), 관리자 목록, 보호 조회/공개 조회, stable-v1 호환, 저장된 참조 변환 및 버전 기반 저장, 공유 모델, 비공개/재공개/만료/환불 보류/삭제 상태 차단, 오래된 버전의 복원 거절과 정상 복원, Storage generation·해시·토큰 존재 유지까지 검증한다.
- 모의 이관의 저장 및 복원은 에뮬레이터의 신규 가상 데이터에 한정된다. 기존 운영 고객·Firebase 환경·Play 배포는 변경하지 않는다. CI 통과 전 실제 통합 검증 완료로 보고하지 않는다.
- 운영 토큰 폐기와 신규 토큰 발급 중단, 구형 앱 및 추억 페이지 전환은 실제 파일럿·클라이언트 검증과 별도 운영 승인 범위에서 수행해야 한다. 기존 토큰은 변경하지 않았으며 운영에서 기존 URL이 차단된다는 보장은 아직 없다.
