# INV-FIX-02-B — 장기 토큰 이관 사전 조사

관리자 이미지 관리에서 선택한 등록 청첩장을 읽기 전용으로 점검한다. wedding-images / memory-images 각 최대 300개 파일을 점검하고 누락 가능성이 있으면 부분 조회로 표시한다. 토큰 값, URL, 파일 경로는 반환하지 않는다. Firestore는 기존 활성 slug index만 직접 읽으며 자동 복구 경로를 호출하지 않는다.

기존 고객 사진, 저장 URL, 다운로드 토큰은 변경하지 않는다. 등록된 활성 slug 외의 redirect/legacy 미등록 경로, 외부 이미지와 CDN 캐시, 브라우저에서 직접 생성한 다운로드 URL, 공유 메타데이터 및 기존 앱의 렌더러는 이 점검 범위 밖이다.

장기 토큰 자체는 계속 유효할 수 있다. 공개 전송/인증된 편집 이미지 전송 설계, 저장 참조 이관, 구버전 호환·재공개 검증, 운영 승인을 거친 토큰 폐기가 후속 작업이다. 점검 수치가 0이더라도 전체 시스템 보안 완료로 간주하지 않는다.
