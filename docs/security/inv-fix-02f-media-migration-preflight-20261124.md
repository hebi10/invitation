# INV-FIX-02-F — 이미지 이관 사전 점검

관리자 이미지 관리에서 선택한 이벤트의 저장 참조, 추억 페이지, Storage 객체 메타데이터를 읽기 전용으로 대조한다. 공개 필드에서 참조되는 동일 버킷/slug의 후보, 토큰 URL 의존, 미지원·누락·미참조 객체 및 추억 페이지 참조를 분류한다. 객체당 메타데이터 기준 검사이며 바이트 검증이나 운영 호환성 보증이 아니다. 최대 300개씩 두 네임스페이스와 제한된 참조 순회만 처리하고 부분 조회를 구분한다.

안전 조건:
- 토큰 값·원본 URL·파일 경로·고객 식별자는 반환/기록하지 않는다. GET만 제공한다. 폐기 허가 값은 항상 false이다.
- 향후 저장된 안정 주소가 실제 이미지 사용처인 경우 삭제 방지에 포함한다.
- 일반 고객·다른 행사·구형 편집기·모바일 업로드/목록·추억 페이지의 직접 토큰 URL 의존은 별도 확인한다. 승인된 파일럿에서 쓰기/읽기 및 롤백 검증 없이 실제 토큰을 폐기하지 않는다.
- 실제 Firebase/웹 배포, 운영 환경 변수 설정, 데이터 변경, 토큰 삭제 또는 Play 배포를 수행하지 않는다.
