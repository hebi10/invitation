# INV-FIX-02 — 이미지 접근 권한 보완 (2026-11-24)

## 이번 변경
- Storage 및 Firestore 공개 읽기 Rules: 삭제 작업 pending/running/failed 동안 하객 읽기를 차단한다. 관리자·소유자 기존 편집 권한은 유지한다.
- 신규 서버 이미지 업로드 3종에는 private/no-store 캐시 정책을 적용한다. 기존 URL/파일/고객 레코드는 수정하지 않는다.
- 에뮬레이터에서 세 삭제 상태의 공개 읽기 거부와 정상 상태 복구를 회귀 검사한다.

## 별도 운영 이관이 필요한 위험 (출시 차단)
Firebase의 장기 다운로드 토큰은 Security Rules의 변경만으로 폐기되지 않는다. 위 변경은 기존 토큰 URL을 무효화하지 않으며 신규 토큰 URL의 권한 우회를 제거하지도 않는다. 따라서 전체 사진 접근 제어 완료로 판정하지 않는다.

안전한 이관 순서:
1. 저장된 청첩장·추억 페이지·공유 카드·기존 모바일/웹 편집기의 이미지 참조 및 토큰 보유 파일을 읽기 전용으로 조사한다. 토큰이나 고객 사진 URL을 로그에 남기지 않는다.
2. 안정적인 이미지 식별자 기반 공개 게이트웨이와 인증된 소유자 미리보기 전송을 개발한다. 공개 게이트웨이는 공개·기간·삭제 상태 및 실제 저장된 참조를 확인하고, 캐시가 비공개 전환 후 재사용되지 않도록 한다. 소유자 편집은 별도의 인증 경계를 사용한다. 공개 문서의 원본 토큰 URL 직접 노출도 제거한다.
3. 테스트 청첩장으로 저장·재편집·미리보기·공유·비공개·만료·재공개·추억 페이지·구버전 호환을 검증한다.
4. 운영 이관 승인을 받은 뒤 새 URL을 우선 적용하고 readback을 확인한 후 기존 다운로드 토큰을 폐기한다. 기존 이미지 및 고객 데이터를 삭제하지 않는다. 이미 다운로드된 복사본은 회수할 수 없다.

이번 PR은 운영 Rules 배포, 토큰 폐기, 고객 데이터 이관, Play 게시를 실행하지 않는다.
