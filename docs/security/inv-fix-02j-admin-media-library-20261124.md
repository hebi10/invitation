# INV-FIX-02-J — 관리자 이미지 목록 안정 주소 호환

관리자 이미지 관리 및 웹 편집기 기존 사진 선택에 서버 조회를 연결한다. 지정 파일럿 웨딩 slug만 보호 목록을 반환한다. Storage 객체 메타데이터만 읽어 안정 게이트웨이 주소로 표시하고 기존 토큰값을 목록 응답에 포함하거나 getDownloadURL로 생성하지 않는다. 300개 초과·부분 조회·경로 오류는 실패 처리하며 SDK 토큰 목록으로 자동 폴백하지 않는다. 다른 slug는 서버의 명시적 legacy 응답에서만 기존 SDK 경로를 사용한다.

대표/본문/썸네일 원본 관계를 유지하며, 미지원 파일은 선택하지 못하게 표시한다. 목록 이미지의 인증 조회는 화면 진입 시 시작하고 원본 등은 명시적 요청에서 읽는다. 계정·경로 변경/화면 종료 시 임시 blob URL을 해제한다. 편집기 선택은 안정 주소를 저장하며 blob URL이나 인증 토큰을 저장하지 않는다. 동일 저장 파일을 가리키는 이전 Firebase URL도 선택/삭제 방지 검사에 포함한다.

제한: 전체 운영 토큰 이관이 아님. 기존 관리자 조회의 저장 참조 API, 일반 공개 관리자 fallback, 이전 앱, 추억 페이지, 업로드 토큰 생성은 별도 검증이 필요하다. 대량 목록/파일럿의 실제 사진 및 브라우저 QA, 운영 설정 활성화, 기존 참조 변환·롤백·토큰 폐기 승인은 남아 있다. 이 PR은 운영 데이터·토큰·Firebase/웹/Play 배포를 변경하지 않는다.
