# INV-FIX-02-K — 저장 이미지 참조 이관·복원 모의검증

## 범위
기존 관리자 읽기 전용 이관 사전검사에 현재 events/{eventId}/content/current의 실제 version/schemaVersion/slug/eventType을 기준으로 변환·복원 모의검증을 추가한다. Storage 파일 경로와 실제 이미지 슬롯 순서는 동일하게 유지하고 알려진 대표·공유·파비콘·갤러리·썸네일·테마별 이미지 필드만 안정 게이트웨이 URL로 변환한다. 메모리에서 원래 슬롯을 복원하고 원본 전체와 깊은 비교를 수행한다. API에는 성공 여부, 저장 버전, 변환 참조·파일 개수만 반환하며 토큰·URL·복원 저널·변환된 문서 본문을 반환하지 않는다.

## 차단 조건
저장 버전 불일치, 미지원 스키마/행사, 불완전 목록, 미지원·누락·미호환 객체, 비이미지 필드 참조, 추억 페이지 참조 또는 저장된 임시 blob/data/file URI가 있으면 변환 성공을 보고하지 않는다. 기존 공개 렌더러와 저장 슬롯 수집 규칙을 공유한다. 모의검증 통과와 실제 이관 승인·토큰 폐기는 별개다.

## 운영 완료 조건
- #146·147·148 최신 HEAD 및 통합 main 검증 성공.
- 파일럿 웹 및 Firebase 운영 환경 반영과 필요한 앱 버전/호환성 검증은 별도 승인 범위에서 수행.
- 실제 테스트 초대장으로 업로드·대표/갤러리·공유·비공개/공개·만료·환불 이용 보류·소유자/관리자 조회를 검증한다.
- 동일 콘텐츠 버전·저장 파일 generation·cross-event/추억/구형 클라이언트 참조를 확인하고, 기존 클라이언트가 토큰을 다시 만들지 않는 것을 확인해야 한다.
- 기존 토큰 생성 및 폐기 전환, 실제 운영 참조 저장/롤백, 운영 토큰 무효화/이전 URL 차단 여부는 미완료다. 토큰을 되살리는 복구를 보장할 수 없으며, 사용자 데이터 변경 및 운영 폐기는 별도 승인과 실제 검증 없이는 실행하지 않는다.

이 PR은 운영 데이터·Firebase Rules·환경 변수·토큰·배포를 변경하지 않는다.
