# INV-FIX-02-D — 공개 화면 이미지 파일럿 연결

선행 #139의 게이트웨이를 테스트 웨딩 slug 한 개의 서버 공개 페이지와 카카오 공유 카드에 연결한다. 기본 비활성. 저장된 config는 변경하지 않고 대표·파비콘·공유·갤러리·썸네일·테마별 이미지 참조의 공개 응답만 게이트웨이 URL로 변환한다. 동일 버킷·동일 slug·허용 확장자를 엄격히 검사하고 잘못된 관리형 URL은 파일럿에서 제외한다. 일반 외부/정적 이미지는 유지한다.

게이트웨이는 실제 이미지 필드만 참조로 인정한다. 일반 문구나 임의 데이터 필드에서 파일을 노출시키지 않는다. 공개 페이지·OG·카카오 카드 모델과 미변경 원본 회귀 테스트를 추가했다.

아직 남은 차단: 운영 파일럿 설정 및 실제 브라우저/Android 고객 편집 검증, 인증된 비공개 이미지 렌더러 연결, 이전 앱의 Firestore 직접 읽기/토큰 생성 제거, 추억 페이지와 구형 slug 이관, 기존 토큰 일괄 폐기. 토큰은 이번 작업에서 폐기하지 않는다. 이미 저장된 URL 또는 외부 서비스 캐시는 이 코드로 무효화되지 않는다. 기존 사용자 데이터나 배포를 변경하지 않는다.
