# INV-FIX-04 — 공개 청첩장·방명록 접근 정책 통합

기존 공개 요약 API와 방명록 API의 독립된 공개 판정이 달랐다. 방명록은 visibility 날짜만 보아 displayPeriod 비활성화/불완전, 삭제 진행 상태를 일관되게 적용하지 못했다.

- 공통 이벤트 요약 공개 접근 판정 함수 사용: 공개 여부, 유효한 활성 노출 기간, 과거 visibility 기간 호환, 명시적 비활성 기간 우선, 삭제 진행/실패 상태.
- 활성 기간의 잘못된 Date 또는 시작 > 종료 차단.
- GET/POST 동일 검증 적용, 차단 이벤트에서는 댓글 조회 및 생성 호출 미실행 확인.
- 기존 공개 승인/콘텐츠 버전 검증 PR #127의 변경은 유지한다.

운영 검수: 테스트 이벤트 제작 → 공개 검토 → 비공개 → 공개 → 기간 시작/만료 → 삭제 진행/실패, 카카오 공유/브라우저/앱에서 확인. 별도 INV-FIX-02의 Storage/Firestore 직접 읽기 및 장기 토큰 이관도 필요하다. 운영 데이터 변경·배포는 이번 PR 범위 밖이다.
