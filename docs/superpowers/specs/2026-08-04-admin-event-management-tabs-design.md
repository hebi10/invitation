# 관리자 이벤트 관리 탭 설계

## 목표

`/admin/?section=events&tab=pages&event=<slug>`에서 열리는 이벤트 상세 팝업 안에서 선택 이벤트의 운영 기능을 탭으로 전환해 관리하고, 필요하면 같은 이벤트가 선택된 전체 관리 화면으로 이동할 수 있게 한다.

## 확인된 기존 동작

- 공개 청첩장 방명록 제목 더블클릭 관리 기능은 현재 `GuestbookThemed`에서 제거된 상태다.
- 제거 직전 구현은 페이지별 평문 비밀번호 입력이 아니라 Firebase 로그인 계정과 이벤트 소유권을 확인하는 방식이었다.
- 현재 방명록 댓글 삭제는 관리자 API 또는 이벤트 소유 고객 API를 통해 권한을 확인한다.
- 레거시 `client-passwords` 기반 평문 비밀번호 기능은 새 인증 흐름에서 사용하지 않는다.

## 팝업 정보 구조

팝업 상단에는 이벤트명과 닫기 버튼을 유지하고 그 아래에 다음 탭을 배치한다.

1. 기본 정보
2. 노출 기간
3. 고객 연결
4. 추억 페이지
5. 이미지
6. 방명록

이벤트가 지원하지 않는 기능은 탭을 렌더링하지 않는다. 기본 정보 탭에는 기존 공개 상태, 상품 등급, 테마, 편집·미리보기, 위험 작업을 유지한다.

## 탭별 동작

### 노출 기간

- 선택 이벤트 한 건의 기간 제한 사용 여부, 시작일, 종료일을 편집한다.
- 시작일이 종료일보다 빠른지 검증한다.
- 저장 또는 기간 제한 해제 뒤 이벤트 요약을 갱신한다.
- `전체 관리 화면` 링크는 `tab=periods&event=<slug>`를 사용한다.

### 고객 연결

- 연결된 고객 계정의 이메일·표시 이름·로그인 제공자를 보여준다.
- 미연결 이벤트는 기존 고객 계정 선택 후 연결하거나 고객 연결 링크를 발급할 수 있다.
- 연결된 이벤트는 확인 후 연결을 해제할 수 있다.
- `전체 관리 화면` 링크는 `section=customers&tab=accounts&event=<slug>`를 사용한다.

### 추억 페이지와 이미지

- 기존 `MemoryPageManager`, `ImageManager`를 재사용한다.
- 팝업에서는 선택 이벤트 slug로 잠가 다른 이벤트로 전환되지 않게 한다.
- 각 탭에 해당 전체 관리 화면 링크를 제공한다.

### 방명록

- 선택 이벤트 댓글만 표시하고 새로고침과 삭제를 지원한다.
- 삭제는 기존 관리자 확인 대화상자와 삭제 API 흐름을 재사용한다.
- `전체 관리 화면` 링크는 `tab=comments&event=<slug>&commentPageSlug=<slug>`를 사용한다.

## 데이터 로딩

- 기본 정보 탭은 현재 페이지 요약을 즉시 사용한다.
- 이벤트 팝업이 열리면 댓글과 고객 계정 쿼리를 활성화해 관련 탭 전환 시 데이터를 즉시 사용할 수 있게 한다.
- 추억·이미지·노출 기간 컴포넌트는 해당 탭이 처음 열릴 때만 마운트해 기존 서비스에서 데이터를 읽는다.
- 저장 뒤 React Query 캐시와 이벤트 요약을 갱신한다.

## 반응형과 접근성

- 기본 정보는 기존 760px 폭을 유지하고 관리 탭은 최대 1100px까지 확장한다.
- 모바일은 화면 여백 12px을 유지하며 탭 바는 가로 스크롤을 허용한다.
- `role=tablist`, `role=tab`, `role=tabpanel`, `aria-selected`를 연결한다.
- Escape, 배경 클릭, 포커스 트랩, 닫기 후 원래 행 포커스 복원은 유지한다.

## 제외 범위

- 공개 청첩장의 숨은 제목 더블클릭 관리 진입 복구
- 레거시 평문 페이지 비밀번호 저장·조회 기능 복구
- Firebase 고객 로그인 비밀번호를 관리자 화면에서 조회하거나 직접 변경하는 기능

## 검증

- 탭 구성과 전체 관리 query를 모델 테스트로 검증한다.
- 선택 이벤트로 잠긴 이미지·추억 관리자를 소스 계약 테스트로 검증한다.
- 타입 검사, ESLint, 전체 테스트를 실행한다.
- 데스크톱과 모바일에서 탭 전환, 팝업 폭, 가로 넘침, 기간 저장 화면을 확인한다.
