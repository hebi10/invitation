# 고객 편집·관리자 웜 그래파이트 UI 디자인

## 목표

고객용 페이지 편집기와 관리자 화면을 하나의 운영 제품처럼 보이게 통일한다. 전형적인 파란 SaaS 스타일, 반복되는 진행 정보, 과도한 둥근 카드와 그림자를 줄이고 차분한 웜 그래파이트 기반의 평면적 작업 UI로 정리한다.

## 적용 범위

- 모든 이벤트 유형의 `/page-wizard` 고객 편집 화면
- `/admin` 전체 관리자 화면
- 관리자 이벤트 상세 반응형 중앙 팝업

공개 초대장, 이벤트별 공개 테마, 고객에게 노출되는 초대장 색상은 변경하지 않는다. 저장·검증·권한·라우팅·데이터 구조도 유지한다.

## 공통 시각 체계

두 작업 화면은 같은 의미 토큰을 사용한다.

| 역할 | 색상 |
| --- | --- |
| 캔버스 | `#F6F6F3` |
| 표면 | `#FFFFFF` |
| 주요 글자 | `#1C1D1A` |
| 보조 글자 | `#666862` |
| 약한 글자 | `#70726B` |
| 구분선 | `#D8DAD4` |
| 강한 구분선 | `#C4C7BF` |
| 주요 동작 | `#292B27` |
| 주요 동작 강조 | `#111210` |
| 선택 배경 | `#EEEFEA` |
| 포커스 | `#596257` |
| 성공 | `#3F7054` |
| 경고 | `#8A6428` |
| 오류 | `#A5423A` |

공통 토큰은 작업 UI에만 적용되는 선택자로 제한한다. 버튼과 입력은 6px, 대화상자와 주요 패널은 8px 반경을 사용한다. 정적인 카드에는 그림자를 사용하지 않고 배경 차이와 1px 구분선으로 계층을 만든다.

## 고객 편집 화면

- 고객의 주 작업은 현재 섹션의 정보를 입력하고 다음 단계로 이동하는 것이다.
- 모바일에서 진행 위치와 섹션 제목이 중복되지 않도록 `1 / N` 표시는 진행 영역 한 곳에만 둔다.
- 입력 오류가 없을 때 나타나는 `현재 입력 중인 항목입니다` 문구는 제거한다.
- 미리보기는 차콜 계열의 보조 동작으로 처리해 입력 행동보다 강하게 보이지 않게 한다.
- 주요 버튼은 차콜 배경, 보조 버튼은 흰 표면과 중립 테두리를 사용한다.
- 입력 필드와 선택 요소의 파란 테두리·포커스 링·선택 배경을 웜 그래파이트 토큰으로 교체한다.
- 기존 데스크톱 2열, 모바일 단일 열, 고정 하단 행동 영역과 모든 입력 필드는 유지한다.

## 관리자 화면

- 운영 정보의 밀도와 표·필터 구조는 유지한다.
- 관리자 전체 셸의 데스크톱 최대 폭을 `1100px`로 제한한다.
- 파란 주요 버튼, 선택 상태, 링크, 포커스 링을 공통 웜 그래파이트 토큰으로 교체한다.
- 성공·경고·오류는 의미 색상을 유지하되 공통 저채도 상태색을 사용하고 텍스트·라벨을 함께 표시한다.
- 카드 반경을 6~8px 수준으로 낮추고 기본 그림자를 제거한다.
- 이벤트 상세는 현재 반응형 중앙 팝업 구조와 내부 스크롤, 포커스 관리 동작을 유지한다.

## 접근성과 반응형

- 본문 텍스트 대비는 4.5:1 이상, 큰 텍스트와 컨트롤 경계·포커스는 3:1 이상을 목표로 확인한다.
- 색상만으로 저장·공개·오류 상태를 전달하지 않는다.
- 모바일 주요 터치 대상은 최소 44px을 유지한다.
- 390px 모바일과 넓은 데스크톱에서 가로 스크롤 없이 동작해야 한다.

## 검증

- 고객 편집기와 관리자 화면을 데스크톱·모바일에서 각각 확인한다.
- 진행 정보 중복 제거, 하단 행동 영역, 팝업 중앙 배치와 스크롤을 확인한다.
- 타입체크, 웹 린트, 관련 UI 계약 테스트와 전체 비에뮬레이터 테스트를 실행한다.
- 실행 중 개발 서버가 공유하는 `.next`와 충돌하는 경우 빌드는 실행하지 않고 그 이유를 보고한다.
