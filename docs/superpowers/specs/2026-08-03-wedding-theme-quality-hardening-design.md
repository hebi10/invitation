# 모바일 청첩장 디자인 품질 보강 설계

## 배경

`emotional`, `romantic`, `simple`, `classic-r` 네 가지 청첩장 디자인을 실제 모바일·데스크톱 화면과 코드로 점검한 결과, 기본 반응형 구조와 빈 데이터 대응은 안정적이지만 공통 갤러리 접근성, 낮은 텍스트 대비, 작은 터치 영역, 감소 모션 미지원, 불필요한 초기 로딩 비용이 확인되었다.

## 목표

- 네 디자인의 시각적 정체성과 현재 데이터/API 계약을 보존한다.
- 키보드와 스크린 리더로 갤러리, 방명록, 일정 탭을 사용할 수 있게 한다.
- 본문 텍스트 대비와 모바일 터치 영역을 WCAG 기준에 맞춘다.
- 실제 콘텐츠보다 오래 보이는 로더와 불필요한 초기 네트워크 비용을 줄인다.
- 테마별 모션, 색상, 타이포그래피 차이를 명시적인 토큰과 계약으로 관리한다.

## 변경 범위

- `src/app/_components/themeRenderers`의 네 웨딩 테마 렌더러와 스타일
- `src/components/sections`의 웨딩 공통 섹션
- 웨딩 페이지에서 사용하는 로더, Kakao SDK 로딩, 샘플 이미지 참조
- 위 동작을 검증하는 스크립트 테스트

관리자 화면, 페이지 위저드, 저장 스키마, 공개 라우트, API 응답은 변경하지 않는다.

## 설계

### 1. 접근성

- 갤러리 썸네일은 이미지 클릭 이벤트가 아니라 이름이 있는 `button`으로 노출한다.
- 라이트박스는 `role="dialog"`, `aria-modal`, 제목 연결을 제공하고 열릴 때 포커스를 이동한다. `Escape` 닫기, `Tab` 순환, 닫은 뒤 원래 썸네일로 포커스 복귀를 지원한다.
- 이전/다음/닫기 버튼에는 한국어 접근성 이름을 제공한다.
- 방명록 입력의 `label`과 입력 요소를 안정적인 ID로 연결하고 성공 메시지는 `status`, 오류는 `alert`로 알린다.
- 일정 선택기는 `tablist`/`tab`/`tabpanel` 관계와 방향키·Home·End 이동을 지원한다.
- 갤러리 대체 텍스트는 단순 번호 대신 신랑·신부 이름을 포함한 문맥을 사용하되, 이름이 없으면 공통 문구로 안전하게 대체한다.

### 2. 색상과 조작성

- 장식용 연한 색은 유지하되 작은 텍스트와 버튼 라벨에는 별도의 고대비 텍스트 토큰을 사용한다.
- Emotional의 골드 텍스트, Romantic의 로즈 텍스트, Classic의 muted 텍스트를 일반 텍스트 기준 4.5:1 이상으로 조정한다.
- 연락처, 지도 토글, 복사 등 주요 인터랙션의 최소 터치 영역을 44×44px로 맞춘다.
- Classic 일정의 활성 탭이 공통 스타일 덮어쓰기에 사라지지 않도록 명시적인 상태 스타일을 둔다.

### 3. 성능

- 로더는 고정된 최소 노출 시간을 강제하지 않고 실제 준비 상태에 따라 종료한다.
- 진행 막대는 레이아웃 폭 애니메이션 대신 `transform: scaleX()`를 사용한다.
- 첫 화면 핵심 이미지만 우선 로드하고 갤러리 이미지는 지연 로드한다.
- 로컬 샘플 이미지는 WebP 파생본을 사용해 전송량을 줄이고 원본은 보존한다.
- Romantic의 외부 폰트 `@import`를 제거하고 프로젝트의 기존 폰트 변수와 제한된 폴백을 사용한다.
- Kakao SDK는 hydration 이전이 아니라 인터랙션 이후 로드한다.

### 4. 모션과 테마 계약

- 반복 장식 애니메이션, 로더, 아코디언 전환은 `prefers-reduced-motion: reduce`에서 정지하거나 즉시 완료한다.
- 모든 전역 애니메이션을 강제로 0.01ms로 바꾸지 않고 웨딩 테마의 실제 모션 클래스만 대상으로 한다.
- Romantic·Classic의 CSS 변수는 로더를 포함한 테마 루트에서 상속되도록 배치한다.
- Classic은 공통 Simple 섹션의 상태를 무조건 덮는 규칙을 줄이고, 루트 테마 속성·CSS 변수·ARIA 상태를 계약으로 사용한다.
- 긴 이름과 버튼 문구에는 안전한 줄바꿈을 적용한다.

## 실패 안전성

- 이미지 URL이나 이름이 비어도 기존 샘플 폴백을 유지한다.
- 외부 지도·공유 SDK가 늦게 로드되어도 정적 주소와 기본 페이지 렌더링은 유지한다.
- 모션 감소와 접근성 속성은 데이터 구조나 서버 저장 값에 영향을 주지 않는다.

## 검증

- 접근성·성능·스타일 계약에 대한 회귀 테스트를 먼저 실패시키고 구현 후 통과시킨다.
- 기존 웨딩 테마 테스트, 전체 테스트, 타입체크, ESLint, 프로덕션 빌드를 실행한다.
- 390px 모바일과 1440px 데스크톱에서 네 공개 라우트를 확인하며, 키보드 포커스·라이트박스·일정 탭·가로 넘침·콘솔 오류를 점검한다.
