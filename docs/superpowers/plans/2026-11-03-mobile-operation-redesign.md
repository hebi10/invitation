# 모바일 운영 화면 리뉴얼

> 실행 기준: 승인된 대화의 모바일 리뉴얼 기획을 순서대로 반영한다.

**목표:** PC 운영 UI의 중립색·직선 형태·작업 중심 구성을 Expo 앱의 목록, 편집, 제작, 안내에 일관되게 적용한다.

**구조:** 기존 Expo Router, 인증 Context, 서버 API, 저장 형식과 결제 이행을 유지한다. 공통 컴포넌트에서 간격과 정보 계층을 정리하고, 네이티브 전체 화면 편집에서 기존 편집 상태와 이미지 정리 흐름을 사용한다.

**기술:** Expo 55, React Native 0.83, React 19, TypeScript.

## 공통 제약

- 밝은 회색·흰 표면·차콜 행동색, 기본 반경 0, 그림자 없음.
- 상태색은 성공·주의·오류에만 사용하고 상태를 문구로도 표시한다.
- 기존 공개 URL, API, 인증·인가, 결제·티켓·연동 복구, 저장 schema 보존.
- 공개 초대장 테마와 PC의 관련 없는 UI는 변경하지 않는다.
- 테스트용 계정·실데이터·비밀값을 소스나 캡처에 넣지 않는다.
- 시각 변경은 lint/typecheck/실제 화면으로 확인하고 저장 행동 변경은 회귀 테스트로 검증한다.

## 작업 순서

- [x] 내 청첩장에 연결 이벤트와 저장 초안을 우선 배치하고 신규 사용자 안내를 제공한다.

### 3. 청첩장 목록과 상세
- [x] 이름·행사일·노출 상태·기간을 요약하고 내용 수정이 우선되는 작업 계층을 적용한다.
- [x] 미리보기·하객용 링크·방명록·기간·기기 연결을 용도에 맞게 정리한다.
- [x] 여러 청첩장 전환과 세션 복구, 기존 작업 권한을 보존한다.

### 4. 제작·안내·설정

- [x] 미처리 결제 복구와 티켓 적용 대상을 분명히 유지한다.
- [x] 이용 안내는 작업별 접힘 목록, 설정은 화면 설정·앱 정보 중심으로 정리한다.

### 5. 검증과 Git 반영
- [x] 변경 전 테스트의 실패를 기록하고 변경 후 결과와 비교한다.
- [x] 모바일 lint/typecheck, 저장 행동 회귀 테스트, 전체 테스트, Expo 웹 export를 실행한다.

## 검증 기록

- npm run check: 통과(웹·모바일 lint/typecheck).
- npm test: 기본·보안·아키텍처 131개 스크립트 통과. 이 실행 환경의 UNIX 소켓 제한으로 tsx CLI 대신 동일 tsx import loader를 사용하는 임시 실행 어댑터를 적용했으며 프로젝트 실행 스크립트의 조건·테스트 목록은 유지했다.
- npm run build: Next.js production build 통과.
- Expo 웹 export: 통과.
- 320·390 폭, 큰 글씨·다크 모드 실제 앱 화면 검수: 실행 오류와 가로 넘침 없음.
- 코드 리뷰: 계좌 예금주의 구분 문자 처리, 키보드 표시 중 편집 공간 부족을 보완했다. 공개 확인 취소도 저장 실패와 분리했다.
- 화면 검수용 임시 design-check 경로는 캡처 후 제거하며 커밋하지 않는다.
- Node 20.20.2에서 기존 관리자 테스트의 ESM/CommonJS Context 중복을 재현하고 테스트 Provider를 같은 모듈 그래프로 로딩하도록 수정했다. production 코드는 변경하지 않았으며 Node 20·24에서 전체 131개 테스트가 통과했다.
