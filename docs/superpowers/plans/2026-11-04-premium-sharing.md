# 프리미엄 상품·카카오 공유 구현 계획

**목표:** 신규 청첩장은 프리미엄 한 종류, 5,000원, 기본 6개월로 제공하고 앱에서 선택한 디자인의 카카오톡 카드를 공유한다.

**기준:** 2026-11-04 사용자 직접 요청. 기존 PC·앱 디자인, 저장 schema와 인증 경계를 보존한다.

**구조:** 상품 가격과 기본 기간은 공용 정책에서 읽는다. 카카오톡 공유는 기존 웹 JavaScript SDK 설정과 공개 초대장 데이터를 사용하며, 앱은 공개 공유 화면을 연다. 실제 전송 대상 선택과 전송은 사용자가 카카오톡에서 수행한다.

## 공통 제약

- 신규 제작 상품은 premium 한 종류, KRW 5,000, 최초 이용 기간 6개월이다.
- 과거 등급·결제 ID·지갑 기록은 호환 읽기를 유지하며 새 등급 선택에는 노출하지 않는다.
- 6개월 종료일은 UTC 달력 월 기준으로 계산하고, 해당 월에 같은 날짜가 없으면 월말로 보정한다.
- 기존 고객의 시작일·종료일을 일괄 덮어쓰지 않는다. PC 관리자 기간 설정을 보존한다.
- 연장 티켓의 개수·가격·권한 정책은 이번 요청으로 임의 변경하지 않는다.
- 공개 전·만료·시작 전·삭제된 초대장의 정보나 미리보기 토큰을 공유하지 않는다.
- 별도 네이티브 SDK가 필요하지 않은 기존 브라우저 기반 카카오 카드 공유를 우선한다.
- 결제 키·비밀번호는 코드, 로그, Git에 기록하지 않는다. 실제 유료 구매를 자동 실행하지 않는다.

## 작업

- [x] 상품 정책: 공용 5,000원/6개월 상수, PC·앱·서버 신규 생성 연결, 단일 premium 표시 및 기존 기록 호환, 안내 문구 수정.
- [x] 공유: 선택 디자인별 공개 주소와 카카오 공유 주소 생성, 앱 공유 진입, 공개 여부/기간 검증, 카드 제목·설명·대표 이미지·실제 공개 링크 전달.
- [x] 결제 연결: 현재 Play 상품/RevenueCat 연결 상태 확인, 사용자에게 필요한 외부 설정을 구체적으로 남기고 가능한 범위의 준비를 완료.
- [x] 검증: 가격 불일치 차단, 과거 등급 권리 유지, 6개월 기본 생성, 비공개·만료 공유 차단, 공유 URL 토큰 제외에 대한 회귀 테스트.
- [ ] 전체 테스트, lint/typecheck/build 및 독립 코드 검토 후 Git 반영.

## 완료 판단

코드 검증과 실제 운영 연결을 구분한다. Play 상품 및 RevenueCat·운영 서버의 설정과 내부 테스트 설치본의 구매/지급 검증이 끝나지 않으면 실제 결제 완료로 보고하지 않는다. 카카오톡 실기기 카드 전송 미검증 여부도 남긴다.

## 검증 및 외부 설정 상태

- 웹·앱 lint/typecheck, 기본·보안·아키텍처 132개 테스트, Next production build, Android Expo export 통과. 로컬 tsx CLI IPC 권한 제한은 저장소 외부의 loader 실행 방식으로만 보정했다.
- 공유 모델은 상대 공개 경로와 상대 이미지 경로를 보존하여 운영·로컬 환경에서 현재 브라우저 origin을 사용한다. 비공개 미리보기 토큰은 공유 주소에 포함하지 않는다.
- Play에 page_creation_premium / premium-6months / 대한민국 KRW 5,000 상품을 임시 저장했다. 활성화·실결제는 수행하지 않았다.
- RevenueCat 로그인 후 Google Play 서비스 계정·상품·앱 공개 키 연결, 운영 서버 키 설정 확인과 1.0.5 내부 테스트 구매·중복 지급 확인이 남았다. 카카오톡 실기기 카드 표시·공유 및 서버 배포도 남았다.
- 기존 1.0.4 배포본과 과거 저장 기간은 이 소스 변경만으로 갱신되지 않는다.
