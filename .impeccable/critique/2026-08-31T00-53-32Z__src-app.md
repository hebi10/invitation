## Design Specificity Verdict

이 프로젝트는 개념적으로 매우 구체적입니다. 홈은 초대장 자체와 제작 후 운영 패널을 한 장면에 배치해 일반 웨딩 랜딩페이지와 구분되고, 공개 초대장은 한국어 조판·사진·긴 여백으로 고유한 에디토리얼 감성을 만듭니다. 위저드 역시 저장 상태, 작업 목차, 단계별 미리보기라는 운영 제품 문법이 확립되어 있습니다.

가장 큰 예외는 `/experience/admin`입니다. `src/app/experience/admin/layout.tsx:11`에는 `data-admin-ui`만 있고 실제 관리자 레이아웃 `src/app/admin/layout.tsx:28`의 `data-operation-ui`가 없습니다. 관리자 CSS 변수는 운영 토큰을 참조하므로 체험 화면의 필터·버튼·상세 패널이 미완성처럼 보입니다.

자동 탐지는 1,112건을 모두 advisory로 보고했으며 색상 588건, 폰트 크기 377건, 반경 147건이었습니다. 공개 초대장 테마까지 운영 UI용 `DESIGN.md`와 비교한 결과가 포함되어 다수는 범위 오탐입니다. 관리자와 위저드 운영 UI의 토큰 드리프트는 수동 평가와 일치하는 고신뢰 신호입니다. 브라우저 보안 정책으로 오버레이 주입은 실패했으며 실제 스크린샷, DOM, 콘솔 로그를 대체 증거로 사용했습니다.

## Overall Impression

제품의 시각적 방향과 사용자 역할 분리는 좋습니다. 가장 큰 기회는 새로운 디자인을 더 추가하는 것이 아니라, 이미 정의된 운영 디자인 시스템과 상태 의미를 모든 체험·편집 표면에 정확히 적용하는 것입니다.

## What's Working

1. 홈의 초대장 미리보기와 운영 패널 조합이 “제작 이후에도 관리되는 초대장”이라는 차별점을 한 장면에 설명합니다. `src/app/page.tsx:133-180`
2. 위저드의 6개 작업 영역, 저장 상태 `aria-live`, 직접 이동, sticky 하단 행동, 미리보기 포커스 복귀가 운영 도구로서 탄탄합니다. `src/app/page-wizard/PageWizardWorkspace.tsx:102-142,157-220,315-343`
3. 공개 초대장은 의미 있는 시맨틱 구조와 고유한 감성 조판을 함께 유지합니다.

## Priority Issues

### P1 — 체험 관리자에 운영 디자인 토큰 누락

- **왜 중요한지:** 핵심 데모가 실제 관리자보다 덜 완성된 화면으로 보이며 제품 신뢰를 떨어뜨립니다.
- **개선:** 체험 래퍼에도 운영 UI 토큰 범위를 적용하고 이벤트 목록·상세 패널을 시각 회귀 대상으로 묶습니다.
- **Suggested command:** `$impeccable polish`

### P1 — 위저드 완료·오류 상태가 실제 진행을 반영하지 않음

- **왜 중요한지:** 새 화면에서 `아직 저장되지 않음`, 입력 전 오류, 미방문 단계의 `완료`가 동시에 보여 진행 규칙을 오해하게 합니다.
- **개선:** `미방문 → 작성 중 → 확인 필요 → 완료`를 별도 상태로 만들고 오류는 blur·다음 이동·제출 이후에 표시합니다.
- **Suggested command:** `$impeccable harden`

### P2 — 디자인을 텍스트 설명만으로 선택

- **왜 중요한지:** 가장 시각적인 결정을 이름과 설명을 기억하며 반복 미리보기해야 합니다.
- **개선:** 실제 대표 프레임 썸네일과 핵심 구성 차이를 한 비교판에 보여주고 중첩 스크롤을 제거합니다.
- **Suggested command:** `$impeccable layout`

### P2 — 관리자 첫 화면의 필터와 선택지가 과밀

- **왜 중요한지:** 관리자의 핵심 목표인 한 건 찾기보다 현황·필터 조작이 먼저 경쟁합니다.
- **개선:** 검색·공개 상태만 기본 노출하고 유형·연결·정렬은 고급 필터로 묶으며 행에 `상세 보기`를 명시합니다.
- **Suggested command:** `$impeccable distill`

### P2 — 공개 초대장의 마지막 인상이 계좌 정보에 머묾

- **왜 중요한지:** 선택 기능이 꺼진 샘플에서 감정적 마무리 없이 금융 정보 뒤에 페이지가 끝납니다.
- **개선:** 선택 기능과 무관하게 이름·감사 문구·공유 행동을 담은 짧은 마감 장면을 유지합니다.
- **Suggested command:** `$impeccable delight`

## Persona Red Flags

- **Alex, 숙련 관리자:** 검색·필터는 많지만 일괄 선택이나 단축키가 없고 상세 진입이 이벤트 이름에 숨어 있습니다.
- **Jordan, 초심 제작자:** 첫 입력 전에 오류를 보고 아직 방문하지 않은 단계가 완료로 표시되어 진행 규칙을 오해합니다. 디자인 이름도 실제 이미지 없이 이해해야 합니다.
- **Sam, 키보드·저시력 사용자:** 시맨틱 라벨과 포커스 복귀는 좋지만 체험 관리자에서 운영 토큰이 빠져 경계·배경·포커스 색의 신뢰성이 떨어집니다.
